# Balance

A responsive, frontend-only people intelligence dashboard demo inspired by the supplied Balance AI prototype.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; it has no build step or package dependencies.

## Deploy

Import this repository into Vercel and keep the project preset set to **Other**. No build command or output directory is required; Vercel serves `index.html` from the project root.

## Demo behavior

Dashboard figures and teammate profiles are sample data. Search, navigation, period controls, report feedback, and check-in actions are frontend interactions; no employee data is stored or sent to a backend.
